# PJR-RBQ9 共有 URL に詰めた世帯の情報が、アクセスの記録や分析の道具に残っていないかを調べる

## 1. 課題内容

結果の共有 URL は、世帯の回答（年齢・収入・居住地・困りごとなど）をクエリに詰めている。Google Tag Manager や Google Analytics、配信先のアクセスの記録が、ページの URL ごと記録していないかを調べ、記録しているなら対策を決める。

## 2. 入力

- 2026-11-15、naoji の質問（テストに固定した共有 URL のキーはセキュリティ的に問題ないか）をきっかけに起票した。テストの固定のキー（`dashboard/src/mocks/shareResultTestUtils.tsx`）は、取り出すと架空のデータ（誕生日 1 月 1 日・収入 0・東京都渋谷区など）で、秘密の情報も入っていないことを orchestrator が確かめた。本物の利用者のリンクを使わないことを、区切り 2.5 のブランチの `bdce692` でコメントに書いた。
- アプリの共有 URL（`/result?share=…`）は、世帯の回答（年齢・収入・居住地・困りごと・制度の金額など）を、誰でも取り出せる形式（base64 と deflate）でクエリに詰めている（`dashboard/src/components/result/shareLink.ts`・`sharePresets.ts`）。
- `dashboard/index.html` は Google Tag Manager（`%=YADOKARI_GTM_ID%`）を読み込んでいる。Google Tag Manager・Google Analytics の設定で、ページの URL（クエリを含む）を記録しているかは、リポジトリからは分からない（管理の画面にある）。本番と開発版の配信先（Cloudflare Pages）のアクセスの記録も、同じく分からない。
- 担当と期限は未定（naoji に確かめる）。

## 3. 影響範囲

| 観点         | 影響                                                                                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| スコープ     | 結果の共有 URL と、Google Tag Manager・Google Analytics・配信先のアクセスの記録                                                                          |
| スケジュール | なし                                                                                                                                                     |
| コスト       | 調べるのは小さい。対策によっては中くらい                                                                                                                 |
| 品質         | 記録していれば、利用者の世帯の情報（年齢・収入・居住地など）が分析の道具や記録に残る。個人情報の扱い（プライバシーポリシー）との整合も確かめる必要がある |
| 関係者       | 結果を共有する利用者、上流の管理者（分析の道具と配信先の管理）                                                                                           |

## 4. 対応方針

| 項目     | 内容                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 原因     | 未確定（記録しているかを調べる）                                                                                                                                                                                                                                                                                                                                                                                                |
| 対応策   | (1) Google Tag Manager・Google Analytics の設定で、ページの URL のクエリ（特に `share`）を記録しているかを、上流の管理者に確かめてもらう。(2) 配信先のアクセスの記録にクエリが残るかを確かめる。(3) 記録しているなら、クエリを記録から外す設定、共有のデータを URL のフラグメント（`#`）に移す（サーバーに送られない）などの対策を比べて決める。(4) アプリのプライバシーポリシー（`PrivacyPolicy.tsx`）の記述との整合を確かめる |
| 依存事項 | 上流の管理者（分析の道具と配信先の管理の画面）                                                                                                                                                                                                                                                                                                                                                                                  |
| 完了条件 | (1)(2) の結果と判断を「5. 対応結果」に書く。対策をとる場合は、その項目を起票するか、ここで直して、共有 URL の復元のテスト（区切り 2.5 の `resultShare.*`、`shareLink.test.ts`）が通ることを確かめる。上流の文書・コードに登録簿の ID を書かない                                                                                                                                                                                 |
